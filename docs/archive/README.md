# Archivio documentazione

Documenti **superati dal ribaltamento di giugno 2026**, quando il bot è
passato dalle strategie volumetriche intraday (Volume Breakout, Mean
Reversion, Liq Squeeze, Imbalance Scalp — tutte bocciate dalla validazione
multi-ciclo) alle strategie quantitative validate (Trend Breakdown,
Funding Squeeze, Macro Core).

Conservati solo come storia del progetto: **non descrivono il funzionamento
attuale**. La documentazione corrente è in [docs/](../index.md), i numeri di
validazione in `microevolutive/` e `data/research/`.

Contenuto: vecchie versioni di architettura/strategie/risk, guide setup e
Docker originali, piani di profittabilità storici, documenti Smart Money /
W/M / contesto mercato, note di progetto iniziali.
